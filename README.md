An interactive, accessible digital classroom web application that supports technology-enabled learning:
lessons, assignments, discussions and per-student progress in one place.

## Features

- **Lessons** – structured content with notes and downloadable material
- **Assignments** – submission, deadlines and teacher feedback
- **Discussions** – threaded Q&A between students and teachers
- **Progress** – dashboards showing completion and scores
- **Accessibility first** – semantic HTML, keyboard-focusable cards, high-contrast theme

## Run

Static front-end — open `index.html` in a browser, or serve it:

```bash
python3 -m http.server 8000
# http://localhost:8000
```
